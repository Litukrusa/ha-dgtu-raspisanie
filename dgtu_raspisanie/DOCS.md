# Расписание ДГТУ

На экране открывается **сегодня**. Кнопки **Завтра**, дни недели и стрелки показывают любой другой день. Данные берутся с сайта университета, логин студента не нужен.

Подходит для 64-битного Home Assistant OS: обычный компьютер и Raspberry Pi 4/5. На 32-битной системе приложение в магазине не появится.

## Установка из терминала

В приложении «Терминал и SSH»:

```bash
ha store repositories add https://github.com/Litukrusa/ha-dgtu-raspisanie
ha apps install 69ec2b06_dgtu_raspisanie
ha apps start 69ec2b06_dgtu_raspisanie
```

Первый запуск собирает контейнер на самом Home Assistant, это занимает несколько минут. Если команда `ha apps` не находится, в этой версии системы она ещё называется `ha addons`, а репозиторий добавляется так: `ha store add https://github.com/Litukrusa/ha-dgtu-raspisanie`.

Адрес репозитория нужно вставить точно так, без `.git` на конце. От него зависит имя приложения: `69ec2b06_dgtu_raspisanie`.

## Какую группу показывать

Откройте **Расписание** в боковой панели. На экране «Выберите группу» введите несколько букв, например `ВИ21` или фамилию, и нажмите на свою строку. Переключатель сверху выбирает ДГТУ или ПИ ДГТУ, группу или преподавателя. Кнопка **Сменить** открывает поиск снова.

## Как открыть расписание

На странице приложения включите **Показывать на боковой панели**. В боковой панели появится пункт **Расписание**.

Откройте его и нажмите **На главный экран**. После обновления страницы на обзоре появится карточка: сегодня, кнопка **Завтра**, дни недели и стрелки. Она использует цвета вашей темы Home Assistant.

Если главный экран собран автоматически и кнопка не смогла вставить карточку сама: на обзоре нажмите карандаш → **Добавить карточку** → **Расписание ДГТУ**.

Обновление с прошлой версии:

```bash
ha apps update 69ec2b06_dgtu_raspisanie
ha apps restart 69ec2b06_dgtu_raspisanie
```

## Обновление и логи

ha apps update 69ec2b06_dgtu_raspisanie
